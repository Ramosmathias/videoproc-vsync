# Provenance

VideoProc est issu d’un projet individuel de parallélisme à Polytech Paris-Saclay. Le cours a fourni le sujet et un squelette de départ. Cette version conserve l’implémentation du projet et remplace le code repris du squelette dans les utilitaires, l’ouverture des flux, la représentation des cellules et l’interface avec le solveur de recalage.

Les vidéos AVI de démonstration et la comparaison WebM sont synthétiques. L’export historique contient les indices et temps des segments calculés sur un essai antérieur.

Le programme utilise une installation externe d’OpenCV et le runtime OpenMP du compilateur. Le script qui retrace les résultats utilise Matplotlib. Ces dépendances s’installent séparément.
